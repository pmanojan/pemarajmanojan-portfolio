## 🛠️ Customization Guide

### Change Personal Information
All personal data is centralized in `index.html`:
- **JSON-LD schema** — structured data for SEO
- **Business card data** — `<script id="business-card-data">` block
- **Meta tags** — title, description, Open Graph, Twitter Cards

### Change Theme Colors
Edit CSS custom properties in `style.css`:

```css
:root {
  --accent: #64ffda;          /* Primary accent (cyan) */
  --accent2: #00b4d8;         /* Secondary accent (blue) */
  --accent3: #7b2fff;         /* Tertiary accent (purple) */
  --bg-primary: #020c1b;      /* Main background */
  --bg-secondary: #0a192f;    /* Card backgrounds */
}

/* Light theme overrides */
[data-theme="light"] {
  --accent: #0d9488;
  --bg-primary: #f8f9fc;
  /* ... */
}
```

### Add New Sections
Follow the existing pattern:
```html
<section id="new-section" class="section">
  <div class="container">
    <header class="section__header" data-animate>
      <span class="section__num">XX.</span>
      <h2 class="section__title">Section Title</h2>
    </header>
    <!-- Content here -->
  </div>
</section>
```
